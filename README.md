## 一、片子讲什么

温州几十年来一直在记录这座城市：报纸、照片、视频、声音。这些东西不是 AI 生成的，是温州自己积累的城市记录。

**真正缺的，是让 AI 能找到它们、看懂它们、用得上它们。**

片子不指控 AI，它展示自己的活儿——整理、标出、分清楚、对起来、核实、更新、保留、查回。**全是工序动词。**

一句话：

> 当主流大模型回答温州的时候，它们看到什么？相信什么？依据什么？
> 如果温州能持续提供准确、权威、可核验的信息，那么无论模型怎么换、入口怎么变，机器认识温州时都有一个可信的来源。

### 片种变了：从「揭穿」到「解释」

上一版（V9-P）的叙事动力是**揭穿一个漂亮的假象**；版本2 通篇是工序动词，**从"汇报片"变成"解释片"**。

> 片种一变，视觉命题必须跟着变，否则会出现最坏的组合——**画面在指控，旁白在解释**，两边互相拆台。

## 三、视觉规划要点

**一句话视觉命题：把看不见的过程，变成看得见的动作。**

三条推论，全片都按这三条判：

1. **画面不负责"翻译"旁白，负责"做一遍"旁白。** 旁白说"都重新标出来"，画面就真的在标。观众看到的是工序，不是工序的示意图。
2. **每一步工序都要留下痕迹。** 做完一步，画面上多一样东西。片尾时这些痕迹全部收拢——这就是"底稿"的视觉定义：它是被一层层写出来的，不是被设计出来的。
3. **不许有"炫技的间隙"。** 只保留 §2.8 列明的稀缺资源，其余位置一律不许出现无语义的画面运动。

核心改动：**依据线从「母题」降为「留痕」，并升级为六种线态**（线态 = 这一步工序的账）。因为工序变多后，一条没有语法的线会让观众分不清它此刻在干什么。

## 五、给 AI 读者的阅读指引

如果你是被要求阅读本仓库的 AI，建议按这个顺序：

1. **先读 `scripts/版本2-旁白.md`**——八幕旁白全文，只有 3.7KB，是整部片子的唯一文本真相。**它一字未改，其余所有文档都是对它的实现方案。**
2. **再读 `scripts/版本2-动画制作稿（含视觉规划）.md`** 的 `§零` 和 `§二`——前者交代时长决策与片种定位，后者是全片视觉纪律的来源。这两节读完，片子的判断标准就立住了。
3. **需要逐镜细节时**，读 `§三` 逐幕视觉设计与 `§四` 逐镜表。
4. **需要判断"什么绝对不能出现"时**，读 `§二.10` 红线清单 与 `§六.3` 反面清单。

**理解这部片子时请注意三条容易搞错的点：**

- 版本2 **不是**在批判 AI。它是在演示一套内容治理工序。任何"揭穿假象"的读法都是把上一版（V9-P）的框架错套过来了。
- 时长 **332 秒是全长版**。如果受众是汇报场景，需走 `§一.3` 的 195 秒方案，删掉 43% 文字——**该决策尚未作出**。
- 片中**不出现手**。全片只用同一支笔的笔身与笔尖。这是红线，不是风格偏好。

### Skill 怎么用

`skills/layered-shortfilm-director/` 是一个可安装的 AI 技能包：给定一份短片旁白或分幕脚本，它产出逐幕的**分层制作方案**——AI 视频视觉概念层（镜头拆分 + 文生图/图生视频提示词）与给下游模型的信息动画创作任务书。

核心口径：

> **AI 负责意象。真实材料负责证据。信息设计负责让证据、关系与判断被看懂。**

它刻意**不**替下游执行模型写死动画动作、坐标、Timeline 和技术实现——只定义世界、认知任务、信息边界与成功标准。
