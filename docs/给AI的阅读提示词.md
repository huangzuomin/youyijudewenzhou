# 给 AI 读者的阅读提示词

本文件是**可直接复制粘贴给 ChatGPT / Claude / 其他 AI** 的阅读指令。目的是让 AI 用正确的框架理解本仓库，而不是套用常见的"批判 AI 幻觉"叙事。

---

## 用法

把下面整段（含链接）粘给 AI。如果 AI 支持浏览网页，它会自己去读；如果它不能联网，则把 `scripts/版本2-旁白.md` 的全文一并粘贴过去。

---

## 提示词（复制以下内容）

```
请阅读这个 GitHub 仓库，然后回答我的问题：

https://github.com/huangzuomin/youyijudewenzhou

这是一个中文短片的制作文档仓库，片名《有依据的温州》，讲的是"温州城市时空可信内容枢纽"。
仓库里有三样东西：
1. scripts/版本2-旁白.md —— 八幕 100 句旁白全文，是唯一文本真相，一字未改
2. scripts/版本2-动画制作稿（含视觉规划）.md —— 332 秒 / 47 镜的完整制作稿
3. skills/layered-shortfilm-director/ —— 把"短片旁白转分层制作方案"流程固化下来的技能包

读的时候请特别注意三点，这是最容易理解错的地方：

一、这部片子不是在批判 AI。它是在演示一套内容治理工序。通篇动词是"整理、标出、
分清楚、对起来、核实、更新、保留、查回"——全是工序动词。任何"揭穿 AI 假象"的读法
都是把上一版的框架错套过来了。

二、332 秒是全长版。如果受众是汇报场景，制作稿 §一.3 有 195 秒方案（删 43% 文字）。
这个决策尚未作出，不要在回答里默认它是 332 秒或 195 秒。

三、片中不出现手，全片只用同一支笔的笔身与笔尖。这是红线，不是风格偏好。

请先读完 README.md 和 scripts/版本2-旁白.md，再按需查制作稿的对应章节。
读完后告诉我：你理解的这部片子的核心论点是什么？
```

## 分场景提示词

### 只想讨论旁白文本

```
请阅读 https://raw.githubusercontent.com/huangzuomin/youyijudewenzhou/main/scripts/%E7%89%88%E6%9C%AC2-%E6%97%81%E7%99%BD.md

这是《有依据的温州》版本2 的八幕旁白全文。请先通读，不要急着评价。
读完后回答：这八幕的逻辑推进关系是什么？哪一幕承担了论证的转折点？
```

### 只想讨论视觉方案

```
请阅读 https://raw.githubusercontent.com/huangzuomin/youyijudewenzhou/main/scripts/%E7%89%88%E6%9C%AC2-%E5%8A%A8%E7%94%BB%E5%88%B6%E4%BD%9C%E7%A8%BF%EF%BC%88%E5%90%AB%E8%A7%86%E8%A7%89%E8%A7%84%E5%88%92%EF%BC%89.md

这是一部 332 秒 / 47 镜短片的动画制作稿，含完整视觉规划。
请重点读 §二 视觉规划 和 §三 逐幕视觉设计。
读完后回答：§2.1 提出的视觉命题是什么？"依据线从母题降为留痕并升级为六种线态"
这个改动解决了什么问题？
```

### 只想了解那套 Skill

```
请阅读 https://raw.githubusercontent.com/huangzuomin/youyijudewenzhou/main/skills/layered-shortfilm-director/SKILL.md

这是一个 AI 技能包的主文件，用于把短片旁白转换成"分层制作方案"。
请读完后回答：它把视觉工作分成哪几层？每层的职责边界是什么？
它为什么刻意不替下游模型写死动画动作和技术实现？
```
